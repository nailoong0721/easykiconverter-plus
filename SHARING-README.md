# EasyKiConverterPlus source sharing snapshot

Snapshot date: 2026-11-14. Upstream base commit: f7ac474.
Upstream: https://github.com/EasyKiconverter/EasyKiConverter/
License: GPL-3.0; see LICENSE and the original copyright notices.

Includes the current Plus working source, local KiCad library-import service,
QML integration and PowerShell importer. Build with CMake and Qt 6 using the
project's CMakeLists.txt, vcpkg.json and tools/build scripts. Windows release
notes describe the Qt 6.8.3 / MinGW 13.1.0 build environment; adjust paths to
your own installation. Do not copy the author's drive paths.

Build output, .git, editor settings and private submission materials are excluded.
This website publication did not rebuild the Windows executable or run a new
conversion regression. Retain the binary's bundled DLL, QML and tools folders.
